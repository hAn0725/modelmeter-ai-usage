# 会话分析

浏览历史聊天会话的逐轮详情 — Token 数、工具调用、耗时等。

![会话详情](https://raw.githubusercontent.com/hAn0725/modelmeter-ai-usage/main/assets/screenshots/session-dashboard.png)

*会话仪表盘把历史聊天活动变成可检索、可探索的工作记录。*

---

## 侧边栏中的会话

在侧边栏 **最近会话** 中可以看到聊天会话，每条显示：

- 厂商与模型名
- 轮次数量与时间
- 预估费用（¥）

点击「查看全部会话」可展开完整列表；点击任意会话打开详情仪表盘。

### 会话筛选

运行 `切换会话筛选` 命令，可按以下条件过滤侧边栏列表：

- 日期范围（最近 7 / 30 / 90 天 / 全部时间）
- 模型（按模型名筛选，只要该会话的任意一轮使用了目标模型，即会出现在结果中）

运行 `清除会话筛选` 可恢复默认视图（最近 7 天）。

---

## 会话详情仪表盘

点击侧边栏中的任意会话打开完整详情：

### 会话概览

- 日期与厂商 / 模型
- BYOK / 内置 标记
- 轮次数（与起止时间）、Token 总量（输入 / 输出）
- 预估费用（¥）与总耗时
- 存在未应用的编辑时的提示

### 输入上下文构成（整个会话）

概览卡下方展示整个会话的输入上下文构成：

- 一条 100% 堆叠色条 + 图例（百分比保留 1 位小数）
- 悬停图例可见「约 X Token」（由“占比 × 输入 Token”反推的估算值）
- 聚合方式为**按输入 Token 加权**（不是对各轮百分比做平均）
- 若部分轮次缺少构成数据，会标注「构成数据覆盖 N% 输入 Token」

### 轮次表格

每一轮包含以下列：

| 列 | 说明 |
|---|---|
| **#** | 原始轮次序号（排序时不会重新编号） |
| **时间** | 本地时间（HH:mm:ss） |
| **模型** | 本轮使用的模型 |
| **输入 / 输出** | Token 数 |
| **输入上下文构成** | 单轮五类占比色条 |
| **预估费用** | ¥（无价格时显示 —） |
| **工具调用** | N / M 轮 |
| **文件** | 编辑文件事件数 |
| **首次响应耗时** | TTFB（首次响应耗时） |
| **总耗时** | 整轮耗时 |

---

## 提示

- 用筛选快速定位某个模型或时间段的会话
- 查看工具调用次数了解工作流的自动化程度
- 对比首次响应耗时与总耗时，发现较慢的服务商或模型
- 仪表盘为只读分析，不会修改 VS Code 状态
